Moodle integration with Cielo.

Kopere Pay's Cielo integration lets you charge for courses by credit card, with e-commerce credentials and instalment rules linked to the enrolment process.

How the integration works →I want to integrate Cielo

Solution used: Kopere PayCredit card payments with Cielo e-commerce.

The Cielo component uses the API 3.0 PHP integration library, requires a Merchant ID and Merchant Key, and lets you configure the maximum number of card instalments.

What should you consider for this integration?

Technical options vary by provider and installed plugin version.

Credit card

Cielo e-commerce payment method supported by the plugin.

Configurable instalments

Set the maximum number of instalments.

Secure credentials

Configure Merchant ID and Merchant Key in the admin settings.

Enrolment linked to payment

Course access is granted after valid payment confirmation.

How to integrate Cielo with Moodle.

The setup process must be verified against the installed Kopere Pay version and the current terms of your payment account.

01

Obtain Cielo e-commerce access

Activate your contracted service and obtain the Merchant ID and Merchant Key.

02

Configure cards and instalments

Enter credentials in Kopere Pay and set instalment limits according to your rules.

03

Test payment authorization and enrolment

Verify payment approval and correct student access before going live.

A payment initiated is not necessarily a payment approved.

Credentials must be kept secure, payment amounts must be validated on the server, and enrolment must only be granted after valid provider confirmation.

Questions about Moodle with Cielo.

Can I use Cielo with Moodle?

Yes. Kopere Pay has a dedicated Cielo e-commerce integration.

Which credentials do I need?

Merchant ID and Merchant Key for your active Cielo e-commerce service.

Can students pay in instalments?

The plugin lets you configure an instalment limit, subject to your account's terms.

This integration is part of Kopere Pay.

You do not need a separate product for each payment method. Kopere Pay centralizes sales and enrolment while each gateway has its own credentials and settings.
