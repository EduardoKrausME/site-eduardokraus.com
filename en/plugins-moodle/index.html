Moodle plugin development.

Do you build exclusive Moodle plugins?

Yes. Work can start from an institution-specific process and result in a dedicated plugin. Scope, maintenance, and usage terms are defined in the quote.

Do you also fix and upgrade existing plugins?

Yes. I can assess in-house or third-party components, check compatibility with new versions, and propose changes when technically feasible.

Will Marketplace be moved to this website?

No. The catalog remains available at eduardokraus.com/marketplace-plugins/. This site presents services and selected projects, with direct links to each one.

Can ChatGPT change Moodle without permission through Moodle MCP?

No. Tools respect the connected account's capabilities. Protected write operations require a preview and explicit confirmation, while read and write tools use separate permissions and endpoints.

Does LearnLingo require Moodle MCP to work?

No. The theme works independently; integration with ChatGPT or Claude (using the MCP protocol) is optional for authorized customization.

Need a feature Moodle doesn't offer yet?

Describe the problem, who will use the feature, and the expected outcome. We can develop a custom plugin, adapt an existing one, or integrate Moodle with a system your institution already uses.
